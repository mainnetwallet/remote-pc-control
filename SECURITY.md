# Security

Remote PC Control can lock, restart and shut down a PC and control its mouse and keyboard, so please report security problems privately.

**Report a vulnerability:** open a private report via GitHub (Security tab, "Report a vulnerability"). Please do not open a public issue for security bugs.

Useful to include: what you did, what you expected, what happened, and the version (commit hash).

Good practice for users: use a long access password (12+ characters), keep the PC reachable only over Tailscale or a Cloudflare tunnel, never commit `.env`, and revoke any token or password that was ever pasted into a chat or an issue.
